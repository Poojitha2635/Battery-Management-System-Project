# Battery-Management-System-Project
This project is an Battery Energy Management System (BEMS) developed using Python, Machine Learning, and Streamlit. It monitors battery parameters such as voltage, current, temperature, charging cycles, and capacity to predict the State of Health (SOH) and detect potential battery faults. The application provides an interactive dashboard for real-time visualization, health prediction, fault detection, and performance reporting. The project demonstrates how machine learning can improve battery safety, efficiency, and lifespan, making it suitable for electric vehicles (EVs) and energy storage systems.
